# Weight provenance and DIMER hosting

- Upstream: `CIDAS/clipseg-rd64-refined`
- Immutable revision: `999e0328d9e10b484360c477313983f9afdd7050` (the Hub's `main` resolved to this commit on 2026-09-14)
- Weight format: SafeTensors (`model.safetensors`, 603,049,496 bytes, float32). The upstream repository also hosts `pytorch_model.bin` (603,143,713 bytes), a pickle checkpoint that DIMER does not accept and this pipeline neither lists nor loads.
- Manifest: `weights/clipseg-rd64-refined/dimer-base-manifest.json` (8 files: `README.md`, `config.json`, `merges.txt`, `model.safetensors`, `preprocessor_config.json`, `special_tokens_map.json`, `tokenizer_config.json`, `vocab.json`; 604,641,231 bytes total, per-file SHA-256)
- Upstream weight license: Apache-2.0 per the Hub checkpoint's `README.md` front matter and licence tag (the CIDAS organisation's Transformers-format release). **Recorded discrepancy, unresolved:** the original code repository `timojl/clipseg` is MIT with its `LICENSE` stating "This license does not apply to the model weights" and its README's Weights section stating "The MIT license does not apply to these weights" without naming another licence for them. This repository follows the Hub tag for the artifact it redistributes and records the discrepancy here and in `MODEL_CARD.md`; a deployment that needs certainty should confirm the weight licence with the upstream authors.
- DIMER hosting: Apache-2.0 permits use, modification, distribution, and commercial use subject to preservation of the licence and notices. The Git repository does not vendor the checkpoint (`weights/**/*.safetensors` is git-ignored); DIMER may mirror the pinned snapshot in its model store under the upstream license.
- Fresh clone: `stage_missing_files(allow_download=True)` fetches only the manifest-listed files absent on disk, at the pinned revision, into the snapshot directory; `verify_snapshot()` then checks every file before any load. `weights/**` is marked `-text` in `.gitattributes` so Windows `core.autocrlf` cannot rewrite the committed small files and break their digests.
- Loader trust boundary: Transformers `CLIPSegForImageSegmentation` / `CLIPSegProcessor` (the slow `ViTImageProcessor` the snapshot declares, 352×352 resize with ImageNet mean/std, plus the CLIP BPE tokenizer with a 77-token context) with `trust_remote_code=False`, `local_files_only=True` from the verified directory; nothing is fetched at construction or inference (the smoke run loaded and segmented with `HF_HUB_OFFLINE=1`).
